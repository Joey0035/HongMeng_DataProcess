# 异常数据处理功能说明

## 概述

本次更新为 `HongMeng_raw_data_Parser.py` 增加了完整的异常数据检测和容错处理机制。
所有检测结果自动写入解包日志 (`*_parse.log`) 末尾的 `[Data Anomalies]` 段。

---

## 一、不完整包处理（头/尾截断）

### 问题
实际采集中，文件首尾可能出现不完整数据包——例如存储启动时写入了部分包、
或文件末尾因断电未写完整个包。

### 解决方案

| 位置 | 处理方式 | 日志记录 |
|------|----------|----------|
| **文件头部** | 逐字节扫描直到找到首个有效同步码 `0xEB90` | `leading_incomplete_data` + 跳过字节数 |
| **文件尾部** | 剩余不足一个完整包的字节直接丢弃 | `trailing_incomplete_data` + 位置和长度 |

前后垃圾数据不会污染解包结果。

---

## 二、伪同步码防御（data_len 上限检查）

### 问题
科学数据区域可能恰好包含 `0xEB90` 字节序列，造成"伪同步码"。虽然校验和可以
拦截此情况，但在校验之前解析器会尝试读取 `data_len` 字段——如果伪同步码后面的
字节被解释为巨大的长度值，可能导致：
- 越界访问缓冲区
- 跳过大量有效数据

### 解决方案
新增常量 `MAX_DATA_LEN = 8192`（最大合法包约 2418 字节，留 2 倍余量）。
在 `_extract_packets_from_buffer` 中，解析 `data_len` 后立即检查：

```python
if data_len < PACKET_DATA_DOMAIN_OVERHEAD or data_len > MAX_DATA_LEN:
    offset = start + 1   # 跳过此伪同步码，从下一个字节继续扫描
    continue
```

这确保伪同步码被快速跳过，不会卡住解析流程。

---

## 三、valid_data_len 与包类型预期值校验

### 问题
即使校验和通过，包内 `valid_data_len` 字段也可能与该类型的标准长度不符
（如 SPEC 应为 2304、TEMP 应为 75），暗示硬件或传输异常。

### 解决方案
在 `parse_packet()` 内，识别出 `pkt_data_type` 后比对预期值。
不匹配时发出 `WARNING` 日志（VNA 因多种频点数天然不固定，不做此检查）。
注意：此包仍保留在结果中，仅做预警。

---

## 四、数据异常检测 (`_detect_anomalies`)

在解包完成后、写日志前，对已解码数据执行以下自动检测：

### 4.1 时间戳异常

| 检查项 | 含义 |
|--------|------|
| `timestamp=0` | 包时间码未写入，通常是硬件启动阶段的无效包 |
| 时间回跳 (Δt < 0) | 时间非单调递增，可能是时钟重置或包序混乱 |

### 4.2 seq_count 间隙

相邻包的 `seq_count` 应连续递增（14-bit 回绕 16383→0 已处理）。
间隙意味着中间有包在传输或存储过程中丢失。日志报告：
- 间隙个数
- 估计丢失包数
- 首个间隙位置

### 4.3 VNA 扫频完整性

| 检查项 | 含义 |
|--------|------|
| 孤立频点数 (singleton) | 某次扫频的频点数独一无二，很可能是首/尾截断的不完整扫频 |
| 频点分组概况 | 列出各频点数×扫频次数，方便快速确认设备配置 |
| 首包缺 group_flag=1 | 第一个 VNA 包不是扫频起始包，说明文件头截断了一次扫频 |

### 4.4 TEMP 全 NaN 行

某个温度包所有 25 个通道解码后全部为 NaN，意味着整包数据无效
（电阻值全部超出 [800, 3000] Ω 范围）。

---

## 五、日志格式

所有异常信息汇总在 `*_parse.log` 最后一段：

```
[Data Anomalies]  (total: N issues)
  [timestamp]
    - SPEC: 3 packets with timestamp=0
    - VNA: 1 time-backwards jumps (first at pkt #42→#43, Δt=-0.001234s)
  [seq_gap]
    - SPEC: 2 seq_count discontinuities, ~5 packets likely lost (first gap at pkt #100: seq 1234→1240)
  [vna_sweep]
    - VNA freq groups: 901pts×20, 1901pts×20
  [temp_nan]
    - TEMP: 4 packets with all-NaN temperature (indices: [0, 1, 2, 3])
```

无异常时显示 `(none — all checks passed)`。
