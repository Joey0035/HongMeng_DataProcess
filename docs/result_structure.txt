result = process_file(file_path) 返回一个 dict，按数据类型分为三个顶层 key：

    result["spec"]   — 相关器数据 (app_id=0x000)
    result["vna"]    — VNA S参数数据 (app_id=0x7FF)
    result["temp"]   — 温度数据 (app_id=0x7C0)

维度说明：
    n_fft   = SPEC 完整 FFT 块数 (每块 64 包)
    n_pkt   = 该类型的原始包总数
    n_sweep = VNA 扫频次数 (按 group_flag 分组)
    n_freq  = 每次扫频的频点数 (可能不同扫频不一致)


================================================================================
  result["spec"]  —  相关器数据
================================================================================

  键                    形状                      类型          说明
  ────────────────────  ────────────────────────  ──────────  ──────────────────────────────
  data                  (n_fft, 4, 4096)          int64       解码后科学数据
                                                               [i, 0, :] = Auto1
                                                               [i, 1, :] = Auto2
                                                               [i, 2, :] = Cross-Imag (互相关虚部)
                                                               [i, 3, :] = Cross-Real (互相关实部)
  raw                   (n_pkt,)                  object      每包原始科学数据 (bytes)
  time                  (n_pkt,)                  float64     每包时间戳 (秒+微秒)
  seq                   (n_pkt,)                  uint16      包序列计数
  src                   (n_pkt,)                  uint8       被测源序列号
  obs_seq               (n_sources,)              uint8       检测到的观测序列（源 ID 按观测顺序）
  metadata              dict →                                per-packet 包头字段
    ├─ app_id           (n_pkt,)                  uint16        应用过程标识符
    ├─ version          (n_pkt,)                  uint8         版本号
    ├─ pkt_type         (n_pkt,)                  uint8         包类型
    ├─ sec_hdr_flag     (n_pkt,)                  uint8         副导头标志
    ├─ group_flag       (n_pkt,)                  uint8         分组标志
    ├─ data_len         (n_pkt,)                  uint32        包数据域字节数
    ├─ valid_data_len   (n_pkt,)                  uint32        有效数据字节数
    └─ checksum         (n_pkt,)                  uint16        校验和

  注意：
  - data 的维度 n_fft = n_pkt // 64，尾部不足 64 包的 SPEC 包被对齐丢弃
  - raw/time/seq/src/metadata 的 n_pkt = n_fft × 64（对齐后的包数）
  - data[i] 对应 raw[i*64 : (i+1)*64] 的 64 个包解码结果
  - obs_seq: RLE 压缩 src，找首个重复出现的源，截取一个完整周期

  使用示例：
    spec = result["spec"]
    fft_0 = spec["data"][0]              # 第 0 次 FFT, shape=(4, 4096)
    auto_1 = fft_0[0]                   # Auto1, shape=(4096,)
    t0 = spec["time"][0]                 # 第 0 包的时间戳
    spec["obs_seq"]                      # 观测序列，如 [30,31,...,45,23]
    spec["metadata"]["app_id"][100]      # 第 100 包的 app_id


================================================================================
  result["vna"]  —  VNA S参数数据
================================================================================

  键                    形状                      类型          说明
  ────────────────────  ────────────────────────  ──────────  ──────────────────────────────
  data                  (n_sweep, n_freq)         complex128  S11 线性复数值
                        或 (n_sweep,) object                  = (Irfl+j*Qrfl)/(Iref+j*Qref)
  raw                   dict →                                原始 IQ 值 (per-sweep)
    ├─ iref             (n_sweep, n_freq)         int64         入射信号 I (48-bit signed)
    │                   或 (n_sweep,) object
    ├─ qref             (n_sweep, n_freq)         int64         入射信号 Q
    │                   或 (n_sweep,) object
    ├─ irfl             (n_sweep, n_freq)         int64         反射信号 I
    │                   或 (n_sweep,) object
    └─ qrfl             (n_sweep, n_freq)         int64         反射信号 Q
                        或 (n_sweep,) object
  time                  (n_pkt,)                  float64     每包时间戳
  seq                   (n_pkt,)                  uint16      包序列计数
  src                   (n_pkt,)                  uint8       被测源序列号
  obs_seq               (n_sources,)              uint8       检测到的观测序列
  n_freq_per_sweep      (n_sweep,)                int32       每次扫频的频点数
  metadata              dict →
    ├─ app_id           (n_pkt,)                  uint16        per-packet 包头字段
    ├─ version          (n_pkt,)                  uint8           ↓
    ├─ pkt_type         (n_pkt,)                  uint8
    ├─ sec_hdr_flag     (n_pkt,)                  uint8
    ├─ group_flag       (n_pkt,)                  uint8
    ├─ data_len         (n_pkt,)                  uint32
    ├─ valid_data_len   (n_pkt,)                  uint32
    ├─ checksum         (n_pkt,)                  uint16        ↑
    └─ calc_total_count (n_sweep,)                uint16      per-sweep 计算请求总计数

  注意：
  - 当所有扫频频点数一致时, data/raw 各字段为规整 2D ndarray (n_sweep, n_freq)
  - 当频点数不一致时, 退化为 (n_sweep,) object 数组, 每个元素为 1D ndarray
  - data/raw/n_freq_per_sweep 按扫频 (sweep) 组织
  - time/seq/src/obs_seq 及 metadata 中 app_id~checksum 按原始包 (packet) 组织
  - metadata 中 calc_total_count 按扫频 (sweep) 组织
  - 扫频通过 group_flag 分组: 1=起始包, 0=续包, 2=末尾包

  每包科学数据域格式 (2404 bytes):
    [0:2]  计算请求总计数 (uint16, big-endian)
    [2:4]  计算请求计数   (uint16, big-endian)
    [4:]   频点数据, 每频点 24 字节:
           Iref(6) | Qref(6) | Irfl(6) | Qrfl(6)   ← 各 48-bit signed big-endian
           最后一包不足部分填充 0x7E

  使用示例：
    vna = result["vna"]
    s11_sweep0 = vna["data"][0]                  # 第 0 次扫频的 S11, shape=(n_freq,)
    mag_dB = 20 * np.log10(np.abs(s11_sweep0))   # |S11| in dB
    phase = np.angle(s11_sweep0, deg=True)        # S11 相位 (度)
    iref_0 = vna["raw"]["iref"][0]               # 第 0 次扫频入射 I
    n_freq = vna["n_freq_per_sweep"][0]           # 第 0 次扫频频点数
    sweep_t = vna["metadata"]["calc_total_count"]  # 各扫频计算请求总计数


================================================================================
  result["temp"]  —  温度数据
================================================================================

  键                    形状                      类型          说明
  ────────────────────  ────────────────────────  ──────────  ──────────────────────────────
  data                  (n_pkt, 5, 5)             float64     解码温度 (℃)
                                                               [i, chip, ch]
                                                               NaN 表示传感器异常或断路
  raw                   (n_pkt,)                  object      每包原始科学数据 (bytes, 75B)
  time                  (n_pkt,)                  float64     每包时间戳
  seq                   (n_pkt,)                  uint16      包序列计数
  src                   (n_pkt,)                  uint8       被测源序列号
  metadata              dict →                                (同 SPEC 结构)
    ├─ app_id           (n_pkt,)                  uint16
    ├─ version          (n_pkt,)                  uint8
    ├─ pkt_type         (n_pkt,)                  uint8
    ├─ sec_hdr_flag     (n_pkt,)                  uint8
    ├─ group_flag       (n_pkt,)                  uint8
    ├─ data_len         (n_pkt,)                  uint32
    ├─ valid_data_len   (n_pkt,)                  uint32
    └─ checksum         (n_pkt,)                  uint16

  注意：
  - 75 bytes/packet = 5 chips × 5 channels × 3 bytes (offset-binary 24-bit ADC code)
  - R = (code − 2²³) × Vref / (2²³ × PGA × Iio)，Vref=2.5V，PGA=1，Iio=0.5mA
  - T = (−A + √(A²−4B(1−R/R₀))) / (2B)，A=3.9083e-3，B=−5.775e-7，R₀=1000Ω
  - R ∉ [800, 3000] Ω 时返回 NaN（传感器异常/未接入）

  使用示例：
    temp = result["temp"]
    t_pkt0 = temp["data"][0]             # 第 0 包温度, shape=(5, 5)
    t_chip0 = t_pkt0[0]                  # 芯片 0 的 5 个通道温度
